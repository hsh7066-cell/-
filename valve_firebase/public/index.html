① [현재 목록 양식 받기] → ② 엑셀에서 수정 (2번째 줄 '예시'와 '작성방법' 시트 참고) → ③ 아래에서 파일 선택 → ④ 미리보기에서 새로 추가 / 엑셀에 없는 밸브 목록이 맞는지 확인 → ⑤ [불러오기]
