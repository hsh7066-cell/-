# 밸브 조작 상태 공유 시스템

사무실 PC 1대를 **서버**로 켜 두면, 같은 Wi-Fi(사내망)에 연결된 휴대폰 10여 대가
브라우저로 접속해서 밸브 OPEN/CLOSE 상태를 함께 보고 바꿀 수 있습니다.
**인터넷 없이** 동작하고, 추가로 설치할 프로그램도 없습니다(파이썬만 있으면 됩니다).

## 구성 파일

| 파일 | 역할 |
|---|---|
| `server.py` | 서버 프로그램. 이것만 실행하면 됩니다. |
| `static/index.html` | 휴대폰에 보이는 화면 |
| `valves.csv` | 밸브 목록(엑셀에서 변환). 서버를 처음 실행할 때 자동으로 등록됩니다. |
| `import_excel.py` | 새 작업 엑셀 → `valves.csv` 변환 |
| `valve.db` | (자동 생성) 사용자·밸브·이력이 모두 저장되는 파일. **이 파일을 백업하세요.** |

## 1. 서버 켜기 (사무실 PC)

1. Visual Studio(또는 명령 프롬프트)에서 `valve_system` 폴더를 열고 실행합니다.
   ```
   python server.py
   ```
2. 처음 실행하면 다음과 같이 나옵니다.
   ```
   아이디: admin   임시 비밀번호: xxxxxxxx
   휴대폰에서:  http://192.168.0.15:8000
   ```
   임시 비밀번호를 적어 두세요(관리자 비밀번호를 잊으면 `python server.py --reset-admin`).
3. Windows 방화벽 창이 뜨면 **"개인 네트워크 허용"**을 눌러야 휴대폰에서 접속됩니다.
4. 작업 기간 동안 PC를 켜 두고(절전 모드 끄기) 이 창을 닫지 마세요.

## 2. 사용자 등록 (관리자)

1. PC 브라우저에서 `http://localhost:8000` → admin 로그인 → 비밀번호 변경
2. **관리자** 탭 → 아이디/이름/부서/임시 비밀번호 입력 → 등록 (10명 정도)
3. 각 사람에게 아이디와 임시 비밀번호를 알려줍니다. 첫 로그인 때 본인이 비밀번호를 바꿉니다.
4. 퇴사·이동한 사람은 **사용중지**, 비밀번호를 잊으면 **비번초기화**.

## 3. 휴대폰에서 사용

1. 사내 Wi-Fi에 연결 → 크롬에서 `http://(PC주소):8000` 접속
2. 크롬 메뉴(⋮) → **홈 화면에 추가** 를 누르면 앱처럼 아이콘이 생깁니다.

### 조작·검증 절차 (2인 확인)

1. **조작자**: 밸브를 실제로 돌린 뒤, 목록에서 밸브를 눌러 `OPEN 했음` / `CLOSE 했음`
   → "명판 확인", "실제 조작함" 두 칸을 체크해야 등록됩니다. 상태: **확인대기**(주황)
2. **확인자**(조작자와 다른 사람): 현장에서 직접 보고 `맞음` → **확인완료**(초록)
   / `다름` → **불일치**(빨강, 사유 메모 필수) → 다시 조작
3. 누군가 상태를 바꾸면 5초 안에 모든 사람의 화면이 갱신되고 알림이 뜹니다.
4. 두 사람이 동시에 같은 밸브를 바꾸면 늦게 누른 쪽은 거절되고 최신 상태를 다시 보여줍니다.
5. 작업요청(요구상태)과 현재상태가 다르면 빨간색으로 표시되고, `요구상태와 다름` 필터로 모아 볼 수 있습니다.
6. **조작 이력** 탭에서 누가 언제 무엇을 했는지 모두 볼 수 있고, CSV(엑셀)로 받을 수 있습니다.

## 4. 새 작업(새 엑셀)을 등록할 때

```
pip install openpyxl            (처음 한 번, 인터넷 되는 PC에서)
python import_excel.py "새작업.xlsx"
```
만들어진 `valves.csv`를 관리자 탭 → **밸브 목록 불러오기**로 올립니다.
(기존 목록은 숨겨지고 이력은 그대로 남습니다.) `CLOE` 같은 오타는 자동으로 CLOSE로 고치고 알려줍니다.

## 설정 바꾸기 (`server.py` 맨 위)

- `REQUIRE_TWO_PERSON = True` — 본인이 조작한 밸브는 본인이 확인할 수 없음
- `SESSION_HOURS = 12` — 로그인 유지 시간
- 포트 변경: `set VALVE_PORT=9000` 후 실행

## 주의

- 사내망 안에서만 쓰는 구성입니다(통신 암호화 없음). 공유기 밖(인터넷)으로 포트를 열지 마세요.
- `valve.db`는 작업이 끝날 때마다 USB 등에 복사해 두세요.
